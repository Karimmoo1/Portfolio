AgriVision AI

Intelligent agriculture management & decision-support system for Egyptian farming

Personal Project · Computer Vision

Deep Learning Face Detection & Recognition

Real-time face detection and recognition pipeline, from video to live webcam

The problem

Recognizing a specific person across video frames in real time needs more than detecting "a face" — it needs a fast, reliable way to say whose face it is.

What I built

A pipeline that detects faces with MTCNN, generates embeddings with a pretrained FaceNet, and matches them against a personal face database using cosine similarity — running live on webcam with bounding boxes and identity labels.

Core capabilities

  • + Real-time face detection
  • + Facial embedding generation
  • + Personal face database
  • + Cosine-similarity matching
  • + Live webcam recognition
  • + GPU-accelerated inference

NTI / ITIDA Training Project · Classical ML

Adult Income Prediction

Predicting whether income exceeds $50K from the UCI Adult / Census dataset

The problem

The dataset is messy and imbalanced — missing values, mixed categorical/numeric features, and far fewer high-income examples than low-income ones — which can quietly wreck model evaluation if left unaddressed.

What I built

A full pipeline that cleans and balances the data, then trains and compares six classifiers to find the one that actually generalizes, evaluated on more than just accuracy.

Core capabilities

  • + Missing-value imputation
  • + Categorical encoding
  • + Class balancing (SMOTE)
  • + Feature scaling
  • + 6-model comparison
  • + Precision / recall / F1 evaluation
Python pandas scikit-learn SMOTE
